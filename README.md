# Здорові Хвостики — поточна версія

Ця збірка базується на актуальних файлах, наданих користувачем.

Поточний app.js уже підтримує:
- завантаження old_price з Supabase;
- закреслену стару ціну;
- нову ціну червоним;
- бейдж знижки у відсотках;
- stock та статус наявності;
- заборону додавання товару при stock = 0.

Перед використанням old_price виконайте `PRICE-MIGRATION.sql` у Supabase SQL Editor.
