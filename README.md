# Здорові Хвостики — Supabase catalog

Сайт з каталогом, підключеним до Supabase (`public.products`).

- Бренд: Здорові Хвостики
- Supabase Project URL: https://eejnxfkuslcaptjkimeg.supabase.co
- Джерело товарів: `public.products`
- Показуються тільки `is_active = true`
- Фото беруться з `image_url`
- `products.js` — лише бекап-приклад, на сторінку не підключається.

## Що нового

1. **Секції каталогу.** Фільтри по категоріях тепер жорстко зафіксовані в `app.js`
   (масив `CATEGORIES`) і показуються в такому порядку:
   - Обладнання та інструменти для грумінгу
   - Годівниці, поїлки та миски для домашніх тварин
   - Туалетні лотки для тварин і аксесуари
   - Ветеринарні препарати та засоби
   - Засоби по догляду за тваринами
   - Іграшки для домашніх тварин
   - Корм для собак і котів
   - Ласощі для домашніх тварин
   - Товари для прогулянок і подорожей з тваринами
   - Догляд та гігієна тварин
   - Спальні місця для домашніх тварин, килимки

   Товар з панелі адміна повинен мати поле `category`, значення якого **дослівно**
   збігається з одним із рядків вище. Якщо значення не збігається (або порожнє),
   товар потрапляє у службову категорію "Інше".

2. **Оформлення замовлення.** Модалка замовлення тепер має дві вкладки:
   - **Самовивіз** — ім'я та прізвище, телефон, магазин самовивозу (одна з 5
     адрес мережі), примітка.
   - **Доставка (Нова пошта)** — ім'я та прізвище, телефон, місто, номер
     відділення/поштомату, примітка.

   Обов'язкові поля перемикаються автоматично залежно від обраної вкладки,
   лист (`mailto:`) формується з відповідним блоком даних.

3. **Акційні товари та залишки.** Картка товару показує:
   - бейдж знижки `-XX%`, якщо ціна зі знижкою (потрібне поле `old_price`,
     більше за `price`);
   - перекреслену стару ціну поруч з новою;
   - кількість на складі (`stock_quantity`): зелений напис "В наявності: N шт.",
     жовтий "Залишилось: N шт." при N ≤ 5, і "Немає в наявності" з
     заблокованою кнопкою "Додати", коли N = 0.

## Необхідна схема таблиці `public.products` для панелі адміна

Крім наявних полів (`id, name, price, description, image_url, is_active,
created_at`), потрібно додати:

| Поле              | Тип     | Опис                                                            |
|-------------------|---------|-------------------------------------------------------------------|
| `category`        | text    | Одне з фіксованих значень зі списку категорій вище                |
| `old_price`       | numeric | Стара ціна (nullable). Якщо `NULL` або ≤ `price` — знижка не показується |
| `stock_quantity`  | integer | Кількість на складі (nullable). `0` → "Немає в наявності"         |

Панель адміна повинна дозволяти вибір категорії зі списку (не вільний текст),
щоб уникнути розбіжностей з фронтендом.

## Файли

- `index.html` — розмітка сторінки
- `style.css` — стилі (включно з бейджем знижки, індикатором залишку, перемикачем самовивіз/доставка)
- `app.js` — логіка каталогу, кошика та форми замовлення, підключення до Supabase
- `products.js` — бекап-приклад товарів (не використовується на сторінці)
