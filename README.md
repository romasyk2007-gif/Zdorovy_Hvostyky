# Здорові Хвостики — каталог

Поточна версія сайту. Додано відображення коду товару та виправлена сумісність залишку:
- код читається з `products.product_code`;
- залишок читається з `stock_quantity`, з fallback на старе `stock`;
- 0 шт. → «Немає в наявності»;
- 1–5 шт. → «Залишилось: X шт.»;
- 6+ шт. → «В наявності: X шт.»;
- кнопка «Додати» блокується при нульовому залишку;
- кошик не дозволяє перевищити залишок;
- `old_price` використовується для знижок.
