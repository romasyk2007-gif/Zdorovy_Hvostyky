# ЗооВетСвіт — GitHub Pages

Готова статична версія магазину для GitHub Pages.

## Файли
- `index.html` — головна сторінка та каталог
- `style.css` — червоно-синій фірмовий дизайн
- `app.js` — пошук, фільтри, кошик та локальна форма замовлення
- `products.js` — демо-товари каталогу
- `assets/` — логотип та фото магазину

## GitHub Pages
У репозиторії встановіть:
- Settings → Pages
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Після push сайт буде доступний за адресою:
`https://ВАШ-USERNAME.github.io/ZooVetSvit/`

## Важливо
Ця версія не має серверної бази даних. Кошик і локальні дані працюють у браузері користувача. Реальну адмін-панель, спільний каталог і збереження замовлень потрібно підключати через backend/базу даних (наприклад, Supabase).
