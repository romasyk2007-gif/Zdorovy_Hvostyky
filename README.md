# ЗооВетСвіт — інтернет-магазин MVP

Статичний магазин, готовий для GitHub Pages.

## Що працює
- адаптивний дизайн;
- каталог товарів;
- пошук;
- фільтри за категоріями;
- сортування;
- кошик з localStorage;
- кількість товарів / видалення;
- форма оформлення замовлення;
- формування листа через mailto;
- блок магазинів і контакти;
- Instagram.

## Важливо
Товари в `products.js` — демонстраційні. Перед реальним запуском замініть назви, ціни, фото та описи на актуальні дані магазину.

GitHub Pages не дає серверної бази даних і онлайн-оплати для такого статичного сайту. Для реальних оплат, залишків і адмін-панелі потрібен backend / SaaS-інтеграція.
